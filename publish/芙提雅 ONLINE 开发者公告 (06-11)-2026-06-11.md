小老师 bot 现在已经部署在 [@狸西娅](https://space.bilibili.com/3546788124428579)​、[@九鬼鬼_DTKuKY](https://space.bilibili.com/91764829)​、[@吸管Xiguan](https://space.bilibili.com/445742313) ​和 [@Woundwort伍德沃特](https://space.bilibili.com/349484111) ​的粉丝群里。感谢所有参与内测、给予支持的分析员！

青尘工作室在近期，通过研发新的插件，对小老师 bot 做了进一步优化。在优化后，对运营策略进行以下调整：

- **调整每日群聊调用量上限**：先前的每日 6M token 硬上限，在部分群聊中可能消耗过快，导致很快触发限流。青尘工作室通过开发新插件，为小老师 bot 引入了 **阶梯式模型调用机制**，将每天的 6M token 上限**提升到 8M** —— 每天前 4M token 使用 GPT-5.5 模型，用量在 4-8M 时，会自动改为使用 **GPT-5.4** 模型进行对话。

- **优化 token 用量**：我们发现，在部分群聊中，单次对话的 token 调用量异常高。针对此问题，青尘工作室开发插件，实现了智能优化 LLM 上下文窗口和缓存命中机制，以解决该问题。目前所有群聊的 token 用量均已恢复正常。

- **取消过载保护限制**：对于 [上一次公告](https://qingchenwait.github.io/fritia_online_guide/announcement.html?id=e88a99e68f90e99b8520online20e5bc80e58f91e88085e585ace5918a20-06-07-2026-06-07) 中提及的 bot 可能触发过载保护的问题，我们通过引入**并发回复**机制，解决了拥塞问题，因此不再实装该限制。但是，需要注意，由于 LLM 回复本身可能存在延迟，小老师 bot **不一定能立即回复召唤对话**。当对话出现延迟时，请耐心等待，**请勿进行多次重复召唤**。



青尘工作室将继续为芙提雅 ONLINE 增加功能、优化使用体验。就让小老师一直陪伴在分析员的身边吧 ~
